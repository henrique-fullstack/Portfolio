## 🇺🇸 English Version

A high-performance, minimalist personal portfolio engineered to showcase clean code, scalable architecture, and modern full-stack development skills. Built with **Next.js App Router**, **TypeScript**, and **Tailwind CSS**.

🔗 **Live Demo:** [portfolio-psi-ivory-68.vercel.app](https://portfolio-psi-ivory-68.vercel.app/)

### 🛠️ Tech Stack & Architecture

This project is built with modularity and performance in mind, using a clean separation of concerns for easy maintenance and scalability:

* **Frontend:** Next.js (App Router), React, Tailwind CSS (Utility-first styling)
* **Language:** TypeScript (Strict type safety across configs and data mappings)
* **Animations:** Framer Motion (Fluid, premium micro-interactions)
* **Icons:** React Icons (`react-icons/si` & `react-icons/fi`)
* **Deployment:** Vercel (Edge network distribution and optimized asset loading)

### ⚙️ Key Engineering Highlights

* **Modular Data Structure:** Project details, tech stacks, and contact channels are decoupled into strict TypeScript configurations (`config/projects.ts`, `config/skills.ts`), allowing instant updates without touching UI components.
* **Custom Brand Integration:** Avoided boilerplate templates by implementing a lightweight, infinite-resolution custom SVG favicon aligned with the hero section's visual identity.
* **Optimized Resource Delivery:** Leveraging Next.js dynamic routing, asset optimization, and strict SEO meta tags for lightning-fast loading speeds and responsive layouts.
* **Explicit Component Mapping:** Robust, case-sensitive dictionary structures to bind data strings directly to external component libraries, preventing layout shifts and rendering errors.

### 🚀 Getting Started

To run a local copy of this project for development or testing, follow these steps:

**Prerequisites**
Make sure you have **Node.js** (v18+ recommended) and **npm** (or pnpm/yarn) installed.

**Installation**

1. Clone the repository:
```bash
   git clone https://github.com/henrique-fullstack/Portfolio.git
```

2. Navigate into the project directory:
```bash
    cd Portfolio
```

3. Install the dependencies:
```bash
    npm install
```

4. Run the development server:
```bash
    npm run dev
```

Open http://localhost:3000 in your browser to see the result.


## 🇧🇷 Versão em Português

Um portfólio pessoal minimalista e de alta performance, projetado para demonstrar código limpo, arquitetura escalável e habilidades modernas de desenvolvimento full-stack. Construído com **Next.js App Router**, **TypeScript** e **Tailwind CSS**.

🔗 **Live Demo:** [portfolio-psi-ivory-68.vercel.app](https://portfolio-psi-ivory-68.vercel.app/)

### 🛠️ Stack Tecnológica & Arquitetura

Este projeto foi desenvolvido com foco em modularidade e performance, utilizando uma separação clara de responsabilidades para facilitar a manutenção e a escalabilidade:

* **Frontend:** Next.js (App Router), React, Tailwind CSS (Estilização baseada em utilitários)
* **Linguagem:** TypeScript (Tipagem estrita em configurações e mapeamentos de dados)
* **Animações:** Framer Motion (Micro-interações fluidas e premium)
* **Ícones:** React Icons (`react-icons/si` & `react-icons/fi`)
* **Deploy:** Vercel (Distribuição em rede Edge e carregamento otimizado de assets)

### ⚙️ Destaques de Engenharia

* **Estrutura de Dados Modular:** Detalhes dos projetos, stacks de tecnologias e canais de contato foram desacoplados em configurações TypeScript estritas (config/projects.ts, config/skills.ts), permitindo atualizações instantâneas sem alterar os componentes de UI.

* **Integração de Identidade Visual:** Substituição de templates genéricos por um favicon SVG personalizado, leve e de resolução infinita, alinhado à identidade visual da seção principal (Hero).

* **Entrega de Recursos Otimizada:** Utilização de rotas dinâmicas do Next.js, otimização de imagens e meta tags rigorosas de SEO para garantir carregamento ultrarrápido e layouts responsivos.

* **Mapeamento Explícito de Componentes:** Estruturas de dicionário robustas (case-sensitive) para vincular strings de dados diretamente às bibliotecas de componentes externos, evitando falhas de renderização.
